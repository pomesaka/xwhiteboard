# xwhiteboard

ローカルだけで動く、会議用のホワイトボード。エージェントが CLI で 1 要素ずつ書き込み、人はブラウザで見て、動かして、直す。外部のサービスにも CDN にもつながない。

## 使う

要るのは [Bun](https://bun.sh) と、PNG の書き出しに使う Chrome（Chromium、Edge、Brave でもよい）。

```sh
bun install                               # チャネルが使う MCP の SDK を入れる
ln -s "$PWD/bin/xwb" ~/.local/bin/xwb     # PATH の通った場所へ
xwb open meeting/20261113.board.json --title "定例"
```

`xwb open` はボードのファイルを作り、サーバーを `127.0.0.1:4747` に立てて、ブラウザで開く。サーバーは 1 つで、どのフォルダのボードも扱う。止めるのは `xwb stop`、ポートを変えるのは環境変数 `XWB_PORT`。

コマンドの一覧は `xwb help`。要素の形と置き方は [docs/agent-guide.md](docs/agent-guide.md)。

## データ

ボードは `<名前>.board.json` の 1 ファイル。1 要素が 1 行なので、リポジトリに入れると差分が要素ごとに出る。画像のファイルを使うなら、ボードと同じフォルダに置く。

## ブラウザでの操作

| 操作 | やり方 |
|---|---|
| 画面を動かす | 2 本指でスクロール。または Space を押しながらドラッグ |
| 拡大と縮小 | ピンチ。または ⌘ を押しながらスクロール |
| 選ぶ | クリック。Shift で足す。何も無い場所からドラッグで範囲を選ぶ |
| 文字を直す | ダブルクリック。⌘Enter か Esc で確定 |
| 文字に装飾を付ける | 編集中に範囲を選んで、⌘B（太字）、⌘I（斜体）、⌘⇧X（取り消し線）、⌘⇧H（蛍光ペン）。上のバーのボタンでも付けられ、蛍光ペンは色を選べる。もう一度押すと外れる |
| 文字の大きさと寄せを変える | 選んで、上のバーの一覧から選ぶ |
| セクションを動かす | 題名をドラッグ。中身も一緒に動く |
| 消す、元に戻す | Delete、⌘Z |
| 動かされないように固定する | 選んで、上のバーの「固定」。固定した要素は、動かせず、直せず、消せない。選んで「固定を外す」で解除 |
| 前面・背面へ動かす | 選んで `]`（前面）、`[`（背面） |
| まとめの帯から付箋へ移る | 帯の行をクリック。元の付箋が画面の中央に来て、選ばれる。行の中身は、元の付箋で直す |
| ガントの日付を変える | 帯の端をドラッグ（開始・終了）、帯の真ん中をドラッグ（全体）。名前はダブルクリック |
| 場所を指して Claude に聞く | 左の「コメント」を選び、ドラッグで範囲を囲むか、クリックで 1 点を指す。書いて「送る」（⌘Enter）。返事が届くと印が青く光る。解決済みにしたコメントは隠れ、右上の「解決済み」で見られる |

人がブラウザで変えた要素は、ボードのファイルの `pending` に記録される。エージェントは `xwb changes <board>` で読み、`--clear` で消す。

## コメントを Claude に届ける（Claude Code のチャネル）

コメントの「送る」を押すと、そのコメントが、Claude Code の[チャネル](https://code.claude.com/docs/en/channels-reference.md)を通ってセッションに届く。Claude は `xwb reply` でそのコメントに返事を書く。チャネルは研究プレビューの機能。

届けたいセッションのプロジェクトの `.mcp.json` に足す。

```json
{
  "mcpServers": {
    "xwb": { "command": "/Users/pomesaka/github.com/pomesaka/xwhiteboard/bin/xwb", "args": ["channel"] }
  }
}
```

セッションは旗を付けて起動する。

```sh
claude --dangerously-load-development-channels server:xwb
```

- 届け先は、作業フォルダの下にそのボードがあるセッション。複数あれば全部に届く。フォルダを変えるなら `"args": ["channel", "--root", "<フォルダ>"]`
- 旗なしで起動したセッションは、届いた知らせを捨てる。`xwb channel` は、親のプロセスの引数に旗があるかを見て、無ければ届け先に数えない。引数を読めない起動のしかたで届け先にならないときは、`.mcp.json` の `env` に `XWB_CHANNEL_FORCE=1` を入れる
- 届け先が無いときに送ると「Claude につながっていません」と出る。本文はコメントに残り、「送り直す」で送れる
- Claude Code は、届いたかをチャネルに返さない。届け先があると判定して送った知らせが捨てられても、画面では分からない
- つながっているチャネルは `xwb channels` で見られる

## セキュリティ

守るものは、ボードの中身（社外の会議の話が入る）と、ボードのファイルへの書き込みだ。サーバーは、ボードのファイルの絶対パスを受け取って読み書きする。そのため、この Mac で同じ利用者として動くプロセスのほかには、使わせない。

### 断る相手

| 相手 | 断り方 |
|---|---|
| ほかのマシン | `127.0.0.1` だけで待ち受ける |
| ブラウザで開いたほかのサイトのページ | `Origin` が付いていたら、xwb 自身のものでなければ 403 を返す |
| ほかのサイトが自分の名前を 127.0.0.1 に向ける攻撃（DNS rebinding） | `Host` が `127.0.0.1:<ポート>` か `localhost:<ポート>` でなければ 403 を返す |
| この Mac のほかの利用者のプロセス | ボードを読み書きする API は、すべてトークンを求める。トークンは `~/.cache/xwb/token`（権限 600）にあり、本人だけが読める |

トークンを求めないのは、画面のファイル（HTML、JS、CSS）と `/api/ping` だけ。`xwb` のコマンドとチャネルはトークンのファイルを読み、ブラウザには `xwb open` が URL の `#k=…` で渡す。PNG の書き出しで起動する Chrome には、トークン付きの URL を書いた一時ファイル（本人だけが読めるフォルダの中）のパスを渡し、起動の引数にトークンを載せない。

トークンを作り直すには、`~/.cache/xwb/token` を消して `xwb stop` する。開いていた画面は `xwb open` で開き直す。

### ボードに書かれたものの扱い

ボードは、エージェントやほかの人が書いたものとして扱い、画面で動くものにしない。

- 文字は、HTML として解釈せずに text として入れる
- 押せるリンクは `http`、`https`、ほかのボード（`.board.json`）だけ。`javascript:` などはリンクにしない
- 画像のファイルは、ボードと同じフォルダより下の、png・jpg・gif・webp・svg だけを返す。`..` や絶対パスは断る
- SVG は `<img>` で描く。SVG の中のスクリプトは動かない
- 外部のサービスにも CDN にもつながない。画面のスクリプトと CSS は、サーバーが手元で組み立てる

### 守らないもの

- **トークンを読めるプロセス**: 同じ利用者で動くプロセスは、トークンを読めば、`.board.json` で終わる任意のパスのボードを読み書きでき、PNG の書き出しを任意の絶対パスに置ける。xwb は、それ以上の権限を分けない
- **ボードのファイル**: 暗号化しない、ただの JSON だ。誰が読めるかは、置いたフォルダとリポジトリの権限で決まる。人が画面で変えた内容も、`pending` としてファイルに残る
- **ブラウザの履歴**: `#k=…` 付きの URL は、ブラウザの履歴に残る。URL を人に渡したり、会話やログに貼ったりしない
- **チャネルで届く文**: コメントの本文と、コメントが指す範囲の要素の中身は、Claude Code のセッションにそのまま届く。ほかの人が書いたボードを開くときは、そこに書かれた指示にエージェントが従わないよう、データとして扱わせる

## 開発

```sh
bun install
bun test
bun run typecheck
```

画面のスクリプトと CSS はサーバーの起動時に組み立てる。`src/client` を直したら `xwb stop` で止めて、起動し直す。画面の色・文字・余白の決め方は [docs/ui-design.md](docs/ui-design.md) にある。
